# Rustbelt Revival Economy

This folder contains the human-readable economy workbook for Rustbelt Revival.

## Authoritative sources

- `backend/server.py` contains the active economy configuration used by the game.
- `frontend/src/game/engine.ts` contains the formulas used for upgrade costs, production timing, contract rewards, badges, restoration bonuses, and XP progression.

The spreadsheet is a documentation snapshot. Update or regenerate it whenever either authoritative source changes.

## Files

- `Rustbelt_Revival_Economy_Bible.xlsx` — dashboard, production recipes, upgrade curves, contract ranges, restoration milestones, XP progression, formulas, and source links.
